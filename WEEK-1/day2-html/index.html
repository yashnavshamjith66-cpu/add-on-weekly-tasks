Understanding Semantic HTML

Published on January 9, 2025

What is Semantic HTML?

Semantic HTML uses meaningful tags that clearly describe the purpose of the content. It improves accessibility, readability, and SEO.

Why Use Semantic Tags?

  • Improves accessibility
  • Makes code readable
  • Better SEO

Common Semantic Tags

Tag Description
<header> Defines page or section header
<article> Independent content block
<section> Defines sections in a document
<footer> Footer for a page or section
